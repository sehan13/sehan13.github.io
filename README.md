# Muhammad Sehan – Portfolio

My personal portfolio website, built with plain HTML, CSS and JavaScript (no frameworks) and hosted on GitHub Pages.

**Live site:** https://sehan13.github.io

> Built with AI assistance (Claude). I customised and reviewed the content and can explain how the code works.

## Features
- Responsive layout that works on phone, tablet and desktop, with a mobile menu
- Dark mode toggle that remembers your choice (`localStorage`)
- Typing animation in the header
- Sections fade in as you scroll (`IntersectionObserver`), with reduced-motion support for accessibility

## Files
- `index.html`: page content and structure
- `style.css`: design, colour themes (CSS variables) and mobile layout
- `script.js`: menu, dark mode, typing effect and scroll animations
